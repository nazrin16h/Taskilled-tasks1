# 📊 Power BI Analytics & Visualization Projects

This repository contains my Power BI data analysis tasks and `.pbix` dashboard files[cite: 5].

### 📁 Files & Overview:
* **`YTO AND YoY.pbix`**: Time Intelligence (YTD & YoY) DAX calculations and comparisons[cite: 5].
